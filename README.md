# Number Guessing Game

A C# console game where the player has to guess a random number between 1 and 100.

## Features

- Generates a random secret number for each game.
- Gives “too high” and “too low” hints.
- Handles invalid text and guesses outside 1–100.
- Counts valid guesses and displays the total when you win.

## How to Run

1. Clone or download this repository.
2. Open the solution in Visual Studio 2022 with .NET desktop development installed.
3. Press Ctrl + F5 to run the game.
4. Enter guesses in the console until you find the secret number.
